# Resumen maestro del proyecto: Café y Esperanza / Café Peregrino

Este documento resume las definiciones visuales, comerciales, financieras y estratégicas construidas durante el desarrollo del piloto de café. Está pensado para migrar el proyecto a otro chat, otro LLM, Canva, Illustrator, Shopify, Google Sheets o una nueva etapa de diseño.

---

## 1. Identidad general de marca

**Marca madre:** Café y Esperanza  
**Producto / línea principal:** Café Peregrino  
**Concepto:** café de origen con identidad espiritual, emocional y de viaje.  
**Territorio narrativo:** montañas, cafetales, peregrinaje, propósito, origen, fe, esperanza, pausa consciente.  
**Lugar de origen comunicado:** regiones montañosas del Meta.  
**Altura usada en storytelling:** 1450 msnm.  
**Frase base de marca:**

> Un café con pasos de peregrino, buscando a aquel que lo creó.

**Versión secundaria usada en comunicación larga:**

> Café de origen de las regiones montañosas del Meta, 1450 msnm. Un café con pasos de peregrino, buscando a aquel que lo creó.

**Tono de comunicación:** directo, emocional, artesanal, limitado, de origen, con propósito. No usar lenguaje demasiado técnico ni textos extensos en piezas de venta. Priorizar claridad, deseo y acción.

## 2. Productos definidos

### 2.1 Excelso

**Nombre en etiqueta:** Café Peregrino - Excelso  
**Rol comercial:** producto de entrada, más intenso, con carácter, ideal para captar clientes.  
**Notas sensoriales finales para etiqueta:**

> Notas intensas a cacao y cítricos.

**Tostión:** Media  
**Molienda:** Fina  
**Contenido neto:** 250 g o 500 g, según presentación.  
**Color identificador recomendado:** magenta como acento principal o paleta contrastante con azul profundo, magenta, turquesa/verde y naranja.

### 2.2 Premium

**Nombre en etiqueta:** Café Peregrino - Premium  
**Rol comercial:** producto de mayor percepción de valor, orientado a upsell y recompra.  
**Notas sensoriales usadas en diseño:**

> Notas a chocolate y cítricos.

**Alternativa de copy sensorial para publicidad:**

> Suave, balanceado y envolvente.

**Tostión:** Media  
**Molienda:** Fina  
**Contenido neto:** 250 g o 500 g.  
**Color identificador recomendado:** naranja / dorado / magenta según aplicación, manteniendo contraste con el Excelso.

## 3. Sistema visual

### 3.1 Paleta principal

Estos son los colores definidos y usados como base del sistema:

| Uso | Hex recomendado |
|---|---:|
| Magenta marca / personaje / emoción | `#F72585` |
| Magenta alternativo más sobrio usado en renders | `#C81D5A` |
| Naranja vibrante / energía / Excelso o acento | `#FF7F11` |
| Azul profundo / confianza / bloque de origen | `#13293D` |
| Verde lima / naturaleza / 100% Colombia | `#A3D75B` |
| Crema de fondo | `#F5EFEA` |
| Texto oscuro | `#2B2B2B` |
| Turquesa/verde usado para diferenciar secciones | `#16A6A3` aprox. |

### 3.2 Regla de uso de color

- El **personaje peregrino** debe ir en magenta.
- El fondo principal de etiquetas debe ser crema, no blanco puro.
- El azul profundo se usa para mensajes de origen o montaña.
- El magenta se usa para historia, marca y emoción.
- El verde/turquesa se usa para naturalidad, Colombia o sostenibilidad.
- El naranja/amarillo se usa para datos técnicos: tostión, molienda y contenido.
- No saturar la etiqueta con demasiados colores fuera de la paleta.

## 4. Tipografías recomendadas

La imagen generada no entrega fuentes exactas, pero estas son las equivalentes reales más cercanas para producción.

| Sección | Estilo | Tipografía recomendada |
|---|---|---|
| Título principal "Café Peregrino" | Sans serif condensada, fuerte, con desgaste leve | Bebas Neue, Anton u Oswald Bold |
| Subtítulos "Excelso", "Premium", "Café de Origen" | Sans serif limpia, mayúscula, tracking amplio | Montserrat Medium, Poppins Medium o Raleway |

**Sistema recomendado para consistencia:**

1. Bebas Neue para títulos.
2. Montserrat para todo el sistema de información.
3. Playlist Script para "Café y Esperanza".

**Textura del título:** aplicar desgaste leve tipo vintage/grunge al texto "Café Peregrino", sin afectar la lectura.

## 5. Personaje de marca

### 5.1 Descripción

El personaje es un peregrino minimalista en estilo vectorial, con las siguientes características:

- Color principal: magenta `#C81D5A` o `#F72585`.
- Hombre barbado, sonriente.
- Sombrero de ala ancha.
- Mochila o bulto de viaje.
- Bastón de caminante.
- Estilo lineal/flat, con contraste en negativo.
- Debe sentirse cercano, noble, artesanal, de viaje y con propósito.
- Puede usarse de medio cuerpo para etiquetas.
- Puede usarse completo caminando para piezas promocionales.

### 5.2 Uso

- En etiquetas: parte superior, centrado.
- En piezas publicitarias: sobre las bolsas o como marca secundaria.
- Para PNG sin fondo: solo el personaje, sin texto, sin fondo, sin sombras fuertes.
- No hacerlo demasiado caricaturesco infantil; debe mantener un estilo limpio, moderno y artesanal.

## 7. Planta de café

### Descripción visual

- Ilustración botánica lineal.
- Ramas con hojas alargadas y serradas.
- Racimos de cerezas de café.
- Debe usarse en baja opacidad o como ornamento de esquina.
- Color recomendado para fondo claro: rosado suave / salmón claro.
- Color recomendado para assets separados: magenta `#C81D5A`.

### Uso

- Fondos de etiqueta.
- Esquinas superiores.
- Decoración sutil alrededor del personaje.
- PNG separado sin fondo para reutilización.

## 8. Packaging

### 8.1 Bolsa base

- Bolsa blanca mate.
- Puede ser bolsa de papel o empaque blanco flexible.
- La etiqueta debe ser el elemento principal, no se debe pintar la bolsa completa.
- Las etiquetas deben ser imprimibles, preferiblemente en PNG 300 dpi o formato vectorial editable.

### 8.2 Formatos trabajados

1. Etiqueta rectangular principal.
2. Diseño de dos medias esferas laterales.
3. Etiquetas separadas por producto.
4. Publicidad vertical para WhatsApp.

### 8.3 Dirección final de etiqueta

La versión final preferida para producción inmediata es la **etiqueta rectangular**, aplicada al frente de la bolsa blanca.

## 10. Etiquetas de media esfera

### 10.1 Concepto

Se trabajó un sistema de dos medias esferas para ubicar en los bordes del frente de la bolsa.

**Forma deseada para el lado derecho:** `|)`  
Es decir: borde recto vertical hacia la izquierda y curva hacia la derecha.

### 10.2 Media esfera de información

Debe incluir:

```text
EXCELSO
TOSTIÓN FUERTE
MOLIENDA FINA
CONT. NETO 250 g
Café y Esperanza - 1 Cor 13:13
```

Luego se ajustó para Premium:

```text
PREMIUM
TOSTIÓN MEDIA
MOLIENDA FINA
CONT. NETO 250 g
Café y Esperanza - 1 Cor 13:13
```

### 10.3 Ajustes definidos

- Los iconos deben ser pequeños.
- "Café y Esperanza" debe ser llamativo pero pequeño.
- Integrar la planta de café dentro del fondo de color, no por fuera.
- Para Premium, fondo magenta.
- Para Excelso, se puede usar naranja o magenta según sistema final.
- Mantener formato PNG de alta calidad para impresión.

## 16. Plan financiero a 6 meses

### 16.1 Objetivo

**Meta:** 13.000.000 COP de utilidad acumulada en 6 meses.

### 16.2 Principio de crecimiento

- No agresivo.
- Empezar con validación pequeña.
- Escalar progresivamente: 10, 20, 30 y luego crecimiento controlado.
- Priorizar recompra y ventas individuales.
- Usar combos solo en fechas especiales y activaciones.

El café es un producto de consumo recurrente. La recompra debe ser gestionada.

### Sistema recomendado

- Día 0: venta.
- Día 7: mensaje de experiencia.

## 22. Reglas finales de diseño

1. Mantener bolsa blanca como base.
2. Usar etiquetas, no pintar toda la bolsa.
3. Usar pocos textos en publicidad.
4. "Peregrino" debe ser más grande que "Café".
5. El personaje debe mantenerse consistente.
6. Los colores deben comunicar diferencia entre Excelso y Premium.
7. El contenido técnico debe quedar abajo, visible pero no dominante.
8. "Café y Esperanza" debe ser pequeño, llamativo y emocional.
9. El CTA debe ser claro: escribir por WhatsApp y reservar.
10. Los combos deben ser percibidos como edición limitada, no como producto permanente.
